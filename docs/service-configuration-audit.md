# Service configuration audit

This file is generated by:

```bash
cd apps/backend
bun --env-file=.env.test run scripts/audit-service-configuration.ts
```

Until that command is run against an isolated database, treat every SKU as **not yet re-audited in this checkout**. Do not copy production ratings, prices, or coverage into this file by hand.

Columns (when generated): service, category, lifecycle, pricing, duration, quantity, variants, addons, materials, equipment, provider requirements, coverage, availability, booking rules, safety, quality, payment, media, SEO, config status.

Statuses used: `READY`, `CONFIGURATION_REQUIRED`, `COMING_SOON`, `PAUSED`, `ARCHIVED`, `INTERNAL`.
