onto the BOOKING — so the fixture never reached the branch that reads a payment row's own
method. That branch is not dead code: homigo_db holds two payments rows with
payment_method='wallet'.

`payWithRealWallet` exists to prevent, so the branch is held by a STRUCTURAL assertion that
says so in its own comment, rather than by a behavioural test pretending to cover it.
